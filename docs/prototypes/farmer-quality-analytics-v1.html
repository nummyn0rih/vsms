Качество и Аналитика фермера

Зеркало разреза /analytics/culture/[id]: там «фермеры внутри культуры», здесь — культуры внутри фермера. Обе вкладки дают только то, чего нет на других: сравнение с другими поставщиками и прогноз/темп. «Качество» — сезонное, отвечает «какой он поставщик»; «Аналитика» — с периодом (SettlementPeriodBar), отвечает «что с ним сейчас и чего ждать». Деньги остаются на «Расчётах», выполнение — на «Контрактах», список партий — на «Отгрузках». Всё считается на лету существующими формулами; бенчмарк — тот же culture-agg.bySupplier. Числа иллюстративные; в проде графики — Recharts.

A · Вкладка «Качество» — сезон целиком, фермер с полными данными
A0
Качество · шапка листа + KPI + таблица «По культурам» + динамика брака
Шапка как на «Расчётах»: имя · сезон · «сформировано» моно справа. KPI: принято · средний брак (взвешенный) · не в зачёт (Σ непринятых категорий, только при наличии calibre-культур) · партий с актом. Ядро — таблица по культурам с бенчмарком: брак у него · брак у ОСТАЛЬНЫХ · Δ · позиция (только при M ≥ 3) · доля в культуре · мини-стек категорий. Строки раскрываются в партии — это переговорный лист. Внизу — динамика брака по неделям (недель с актами 9 ≥ 4). Δ — без алярм-красного: инструмент разговора, не авария.

B · «Качество» — краевые состояния
B1
Только simple-культуры · единственный поставщик (M < 3) · мало недель для графика
Три деградации в одном листе. KPI «Не в зачёт» скрыт — категорий калибра нет ни у одной культуры (плиток три, не четыре). Решения / вопросы

Зафиксировано при сборке v1 — на ревью подтвердить или развернуть.

Граница между вкладками
решено«Качество» — только сезон, без переключателя периода: качество за неделю — это одна-две партии, шум. «Аналитика» — с периодом (SettlementPeriodBar, состояние в URL). Сезонные метрики на «Аналитике» подписаны как не зависящие от периода, чтобы «Выполнение 71%» не читалось как результат выбранной недели.
Позиция и Δ вместо рейтинга
решеноПозиция — только при M ≥ 3; ниже — прочерк с подсказкой «мало поставщиков для сравнения». Δ — со средним по остальным поставщикам (сам фермер исключён), знак важнее величины, без алярм-красного: «хуже» — приглушённый янтарь, «лучше» — приглушённый зелёный.
Деградация графиков
решеноПорог — 4 недели с актами. Ниже порога вместо линии таблица недель с подписью «для графика мало точек». Одинаково на обеих вкладках.
Что НЕ дублируется
решеноДенег на «Качестве» нет (BR-33), выполнение по контрактам — цифрой на «Аналитике», но детализация остаётся на «Контрактах»; раскрытие партий на «Качестве» показывает только веса/проценты/категории, без статусов и логистики — полный список на «Отгрузках».
1 · Достаточно ли Δ и позиции для разговора?
вопросСейчас «худшие партии» видны только внутри раскрытой культуры (подсвечены тоном). Альтернатива — отдельный блок «5 худших партий сезона» поперёк культур: короче для разговора, но добавляет ещё один список к тем, что уже есть на «Отгрузках». Нужен?
2 · «Ритм поставок» — польза или метрика ради метрики?
вопросОставлен в макете (C1 показывает, зачем: «17 дней при интервале 6» = пропал). Если это читается из «Динамики приёмки» — блок убираем, останется одна плитка «последняя поставка N дней назад».
3 · Нужен ли период на «Качестве»?
вопросПредложено сезонное. Если запрос «как он вёл себя в августе» реален — период добавляется тем же компонентом, но тогда нужен порог: при < 5 партий в периоде показывать таблицу партий, а не проценты и Δ (иначе бенчмарк сравнивает шум с сезонным средним).
4 · «Не в зачёт» как KPI
вопросПлитка показывается только при наличии calibre-культур (в B1 её нет). Но у смешанного фермера это Σ по одной культуре из четырёх — цифра честная, читается как общая. Оставить с подписью «только Огурцы» или перенести в строку таблицы?

Считается на лету, ничего не хранится. Переиспользуются computeWeightedBrak · computeAcceptedKg / computeAcceptedPercent · categoryShares + compareCalibreRanges · getContractExecution · getFarmerCard · TripWeightNorm. Бенчмарк — разворот culture-agg.ts / bySupplier, второй агрегации нет. Год-к-году (этап G), печать/экспорт этих вкладок — вне среза. Числа иллюстративные.

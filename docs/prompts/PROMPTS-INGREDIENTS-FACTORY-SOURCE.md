# PROMPTS — ingredients-factory-source: завод как безлимитный источник ингредиентов

> Экран `/ingredients`. Меняется **смысл отображения, а не леджер**: для ингредиентов завод — внешний
> безлимитный источник, его остаток не отслеживается. **Миграции НЕТ, движения не трогаем.**

## Доменное решение (согласовано с пользователем)

Формулировка пользователя: «на заводе всегда есть ингредиенты, мне не нужно знать сколько их там; мне нужно
знать, сколько я забрал за сезон и кому передал».

| | Тара | **Ингредиенты** |
|---|---|---|
| Завод | Полноценная локация: тара **возвращается**, остаток реален и нужен | **Внешний безлимитный источник**: обратного потока нет, ингредиент уходит в производство |

⚠ **Правило только для ингредиентов.** Для тары завод остаётся локацией — не трогать `/packaging`.

**Леджер не меняется.** Доставка по-прежнему пишется `завод → транзит(−2) → фермер`, расход — `фермер → null`.
Меняется отображение и трактовка. Решение обратимо: если когда-нибудь понадобится учитывать склад завода,
данные на месте.

## Что меняется на экране

| Было | Стало |
|---|---|
| KPI «На заводе» (`app/(app)/ingredients/page.tsx:46`) | **Убрать.** Вместо — «Забрано со склада за сезон» (общая цифра по ингредиенту) |
| Строка «Завод» в таблице (`IngredientBalanceMatrix`) | **Убрать** — показывает остаток бесконечного источника, то есть бессмыслицу |
| «Итого в системе» (`IngredientBalanceMatrix.tsx:232`, пояснение `:372`) | Переименовать в **«Итого у поставщиков»** + поправить пояснение: завод в сумму не входит |
| История движений (леджер по фермер×ингредиент) | **Добавить блок-шапку**: остаток на начало сезона · поступило с завода · израсходовано в производство |

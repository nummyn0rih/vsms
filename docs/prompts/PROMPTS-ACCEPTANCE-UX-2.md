# PROMPTS — acceptance-ux-2: карточки приёмки + правка акта

> Пять доработок экрана `/acceptance` из пользовательского бэклога. **Миграции НЕТ.**
> Пункты 1–4 — вёрстка/подача, пункт 5 — новая возможность (правка акта без отката).

## Пункт 5: почему правка акта безопасна

Пользователь просит менять акт без цепочки откатов (типовой случай: акт заполнен, позже нужно проставить
`settlement_percent`). **Логике проекта это не противоречит:**

- `saveAct` пересохранение уже поддерживает — в `w5a-weight-edit-FIX` это сохранено явно
  («пересохранение акта БЕЗ изменения веса должно продолжать работать»);
- **фактический вес заблокирован** тем же фиксом, а расход ингредиентов считается ОТ ФАКТА → правка процентов
  и корректировки **не трогает склад**, меняет только деньги и выполнение контракта;
- не хватает лишь UI: у `AcceptedMachine` есть только `revertAct`, кнопки правки нет.

Если бы вес оставался редактируемым, правку без отката делать было бы нельзя — леджер разошёлся бы с перевеской.

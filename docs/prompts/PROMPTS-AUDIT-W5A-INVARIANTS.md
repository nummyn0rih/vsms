## Что закрываем

**П-11 — гард расхода ингредиентов по СУЩЕСТВОВАНИЮ, а не по нетто.** `server/acceptance/act.ts:465–472`:
```
const already = await tx.stockMovement.count({ where: { source_doc_type:"acceptance_act", source_doc_id: act.id, kind:"ingredient" }});
if (already === 0) { …списываем… }
```
Это прямое нарушение правила проекта №7 (CLAUDE.md): «любое НОВОЕ плечо — гард по НЕТТО группы, не по
существованию». Сейчас спасает только то, что откат удаляет акт и новый акт получает новый `id`, то есть
`source_doc_id` меняется. Как только откат перестанет удалять акт **или** появится пересчёт расхода при правке
веса — повторное применение молча пропустится. Это дословный сценарий бага materials-fix, на котором правило и
было выработано.

**П-9 — гонка авто-перехода в `accepted`.** `act.ts:438–441`: `stillUnaccepted` считается `count` внутри
транзакции. Две параллельные приёмки последних двух позиций могут обе увидеть «ещё есть непринятые» → машина
навсегда останется `arrived` при всех принятых позициях. Чинится только повторным пересохранением акта.

**Гард BR-33 (новое, из разбора прод-данных).** Найден реальный дефект на проде: у партии с
`settlement_percent = 97` категория «свыше 12» (`is_accepted = false`) имела `contract_line_id`. В итоге
нестандарт оплачивался **дважды**: целиком по строке контракта (правило C3d-2, гейт оплаты
`contract_line_id != null`) и ещё раз внутри доплаты. Ошибка стоила +712,4 кг и +39 894 ₽ на одной партии и
исказила «Принято» на экране контракта. Данные пользователь исправил; **механизм остался открытым**.

## Решения (зафиксированы)

| Развилка | Выбор |
|---|---|
| Модель BR-33 | **Остаётся вариант 2: `к оплате = actual × settlement_percent`.** Формула уже реализована так и МЕНЯТЬ ЕЁ НЕ НУЖНО. Разнесение доплаты по строкам с разными ценами отвергнуто — на практике не применяется |
| Совместимость с C3d-2 | Два механизма оплаты нестандарта (своя строка контракта vs `settlement_percent`) **взаимоисключающие**. Комбинация = двойной счёт → **запретить валидацией**, а не «складывать аккуратнее» |
| Где запрещать | На сохранении акта (сервер), с человеческим сообщением. Плюс подсказка в UI формы акта |
| П-11 | Заменить `already === 0` на нетто-гард по группе, как в остальных плечах склада |
| П-9 | Пересчёт статуса машины идемпотентным шагом; блокировка строки отгрузки в транзакции |
